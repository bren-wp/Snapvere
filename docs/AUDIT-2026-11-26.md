## Follow-up on the v0.2.36 candidate

The first candidate quality run (45734077025) passed frontend, RustSec, isolated PipeWire and isolated Wayland jobs. Both native build jobs failed on the same Rust formatting difference in gallery_helpers.rs, before native tests. This follow-up applies that exact correction. Startup rollback now retains the journal if both original and staged paths are absent, and checks the existing original before forgetting the intent. A regression simulates a replaced empty media directory and restores the original after its return. This is a conservative recovery guard, not durable inode/file-ID verification; committed cleanup and live rollback still require identity protection. Fresh CI is required.

## Persistent identity follow-up

Candidate adds schema v2, Linux device/inode and Windows volume/file-index identity, records parent and leaf before staging, and verifies them at each stage/restore/cleanup. Legacy intents without identity are retained, not guessed. Tests cover a substituted regular staging file and unverified legacy journal. Residual: path-based rename/unlink still has a same-user leaf race, identity reuse is possible, and native tests and power-loss durability must be verified. The preceding Wayland CI failed at Sway IPC readiness, before portal acceptance; bounded readiness polling is added without retrying the actual capture assertion.

## Native cleanup and directory durability follow-up

Windows committed cleanup now opens with DELETE access and denies write/delete sharing, validates the opened identity and requests FileDispositionInfo on that same handle. A Windows-only regression covers locked files, wrong identity and successful removal. Linux syncs pinned directory entries before SQLite commit and after restore/cleanup; unsupported sync fails closed. Linux leaf unlink and both platforms' rename operations still lack atomic identity-conditional operations. Windows directory persistence, identity reuse and physical power-loss tests remain open. Isolated SQLite 3.46.1 tests passed migration/legacy preservation, rejection of legacy and missing-thumbnail identities, rollback, and commit persistence across reopening (not bundled native SQLite). Wayland readiness correction passed its preceding exact-commit CI job. New candidate changes require fresh CI.
