# Website CSP and zero-telemetry policy — 22 November 2026

The public site does not include Google Analytics, advertising trackers,
measurement scripts, tracking cookies, or click/download interaction events.
The deleted `site/analytics.js` must not be restored. Capture data and history
remain local to the desktop app.

Both `site/_headers` and `netlify.toml` carry the same deny-by-default CSP.
JavaScript is same-origin plus reviewed SHA-256 hashes for three structured
data/bootstrap script blocks. `connect-src 'self'` and `img-src 'self' data:`
prevent calls to third-party endpoints. Self-hosted fonts avoid third-party
font requests. The existing decorative HTML style attributes still require a
style-only `'unsafe-inline'` exception; JavaScript does not have it.

CI checks: `python tools/check_site_csp.py`,
`python tools/check_no_backdoor_patterns.py`, and
`node --test tools/tests/analyticsConsent.test.mjs`.

**Limitations:** Netlify/web-host access logs must process IP addresses to
serve pages/downloads. These are not application telemetry, but no public
website can guarantee that no connection metadata reaches its host.
Production CDN headers and browser network traffic still need physical QA.
