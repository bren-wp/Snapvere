SNAPVERE UPDATE CENTER — English deployment
Extract all files directly into the document root of update.snapvere.com, including .htaccess. Requires PHP 8.1+ and Apache 2.4 with mod_headers and mod_rewrite, plus DNS and HTTPS. No database or Node process.
This update-only catalog excludes full Setup, MSI, DEB, Portable EXE and AppImage files. The latest published release number is informational. A compatible delta is listed only after its exact base version, edition, platform, actual file length and SHA-256 are verified. No update binaries are fabricated. The initial catalog has no patches until a real delta build is published.
Windows dedicated artifacts: Snapvere-Update.exe and Snapvere-Pro-Update.exe. Linux: Snapvere-Linux-Update.svpatch and Snapvere-Pro-Linux-Update.svpatch. These names are a reserved distribution contract, not working binaries yet. Place verified updates at patches/<target>/<base>/<name> with the matching catalog entries. Direct access is blocked by .htaccess; download.php validates and streams the exact file. Do not copy full installer binaries under update filenames. Automated patch generation, signed verification and safe application/rollback require further implementation. Never automatically execute an unsigned update.
