SNAPVERE UPDATE CENTER — English deployment
Extract every file directly into the document root of update.snapvere.com, including .htaccess. PHP 8.1+ and Apache 2.4 with mod_headers are required. DNS and HTTPS must be configured by the host. No database, Node process, account or cron is required.
The included stable.json lists ten published binaries with sizes and SHA-256 digests reported by the official GitHub release API. The release is public and marked stable; installers may be unsigned. No installer is included in this archive. Downloads redirect to the official versioned release assets. No unpublished version is advertised.
When a new verified stable release is published, replace stable.json atomically with the release's Snapvere-update-stable.json (full ten-package catalog). This package does not automatically poll GitHub for new releases. Confirm the live HTTPS manifest is JSON, Access-Control-Allow-Origin is *, and all download links reach the expected package. Do not mix Free/Pro or Windows/Linux packages. On non-Apache hosts configure equivalent headers and directory access restrictions.
