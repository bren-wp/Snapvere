Verify the matching release assets

  1. 01

    Choose the same edition and version

    Select the Tauri/Rust release version offered by your installed app. Preview builds do not have confirmed full physical Windows acceptance.

  2. 02

    Check the downloaded package

    Use the Snapvere-Portable.exe, Snapvere-Setup.exe or Snapvere-Setup.msi assets and SHA256SUMS.txt from the same release. SHA-256 confirms file integrity, not publisher identity.

  3. 03

    Do not switch editions in place

    Do not install WinUI files over Tauri or Tauri files over WinUI. Back up local captures and settings before any manual migration; an automatic migration path has not been verified.

Installer signing, upgrade/uninstall behavior and physical Windows 10/11 QA require independent verification. Unsigned previews are not production-certified.
